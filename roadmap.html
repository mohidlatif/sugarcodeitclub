Road Map

Where We Go From Here

Our road map focuses on strengthening project-based learning, improving documentation, expanding outreach, and creating resources for future officers.

2025–2027
Completed
2025–2026

Build the foundation

Establish the club's learning, project, and online resources while building a clear record of what members actually accomplish.

  • Develop Arduino, engineering, and bioengineering activities
  • Complete and document 22 projects
  • Document meetings and completed projects
  • Build and improve the Sugar Code It website
  • Represent Sugar Code It at events such as Ranger Camp
Current
2026–2027

Strengthen the program

Build on the club's existing foundation by improving the learning experience, project work, documentation, participation, and outreach.

  • Continue the structured electronics and Arduino learning path
  • Improve project documentation with photos and descriptions
  • Build on strong participation, including a record attendance of 60 students
  • Expand hands-on engineering challenges and project work
  • Create more opportunities for teaching, volunteering, and STEM outreach
  • Continue maintaining and improving the club website
Looking Ahead
Future

Make it easier to continue

Organize what the club creates so future members and officers can build on existing work instead of starting over.

  • Build a reusable collection of lessons and project resources
  • Keep an organized archive of completed projects and club activities
  • Document outreach and participation more consistently
  • Prepare resources future officers can update and continue
  • Create more opportunities for members to lead projects and workshops
